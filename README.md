# One-Line Slogan for a Solana Wallet Agent

## Entry

> Your Solana wallet finally talks back — send, swap, and stake with one sentence.

## How to run

```bash
python3 main.py
```

To also write the slogan to a file, set `MAKEFUN_OUTPUT` to a path before running:

```bash
MAKEFUN_OUTPUT=./entry.txt python3 main.py
```

The slogan is 14 words, a single line, deterministic, and uses only the Python standard library.
